# Credentialing – Medical Billing

## Overview

Provider credentialing is an important component of Revenue Cycle Management. It ensures that healthcare providers are properly enrolled and credentialed with insurance payers so that claims can be submitted and reimbursed correctly.

This module demonstrates the credentialing workflow, payer enrollment process, documentation tracking, follow-up, and status management.

---

## Credentialing Workflow

1. Collect provider information
2. Verify provider credentials
3. Verify NPI information
4. Verify taxonomy and specialty
5. Review state license
6. Review DEA/CDS information when applicable
7. Prepare payer enrollment application
8. Submit application to insurance payer
9. Track application status
10. Respond to payer requests
11. Complete payer enrollment
12. Verify effective date
13. Update billing system
14. Monitor re-credentialing requirements

| Status | Meaning |
|---|---|
| Not Started | Credentialing has not started |
| Documentation Pending | Required documents are missing |

| In Progress | Payer is reviewing application |
| Additional Information Required | Payer requested more information |
| Approved | Provider approved by payer |
| Denied | Enrollment was not approved |

| Re-Credentialing Due | Provider requires renewal |

## Common Credentialing Issues

### 1. Missing Documentation

Required documents may not have been submitted or may have expired.

### 2. NPI Information Mismatch

Provider information may not match between enrollment records and payer records.

### 3. License Expiration

An expired license can delay credentialing or enrollment.

### 4. Application Delay

Payer processing may take longer than expected.

### 5. Additional Information Request

The payer may request additional documentation or clarification.

### 6. Incorrect Provider Information

Errors in specialty, taxonomy, address, TIN, or other provider information can cause delays.

## Objective

The objective of credentialing management is to ensure that providers are properly enrolled with insurance payers, maintain accurate provider information, reduce enrollment delays, prevent credentialing-related claim issues, and support timely reimbursement.
