# RCM Medical Billing Project

## Overview

This project demonstrates an end-to-end Revenue Cycle Management (RCM) workflow covering key medical billing and healthcare revenue cycle functions.

The project is designed as a practical portfolio demonstration of RCM operations, claim lifecycle management, accounts receivable, denial management, electronic transactions, and performance analysis.

All data used in this repository is fictional and created for portfolio demonstration purposes.

## End-to-End RCM Workflow
